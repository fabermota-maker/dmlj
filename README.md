# Journey Estoque — PWA

Pacote completo para publicação no GitHub Pages.

## Arquivos

- `index.html`
- `manifest.json`
- `service-worker.js`
- `icon-512.png`
- `icons/icon-192.png`
- `icons/icon-512.png`

## Publicação no GitHub

1. Envie todos os arquivos e a pasta `icons` para a raiz do repositório.
2. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
3. Aguarde a publicação.
4. Abra o site e atualize a página uma vez.
5. No celular, use **Adicionar à tela inicial** ou **Instalar aplicativo**.
